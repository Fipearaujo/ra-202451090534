# Instruções do repositório

## Commits

**Não adicionar o Claude como coautor neste repositório.**

Nunca incluir o trailer `Co-Authored-By: Claude ...` (ou qualquer variação
que atribua autoria/coautoria ao Claude, Anthropic ou Claude Code) em
mensagens de commit. O mesmo vale para descrições de pull request: nada de
rodapé "Generated with Claude Code".

Todos os commits devem ter apenas o autor humano do repositório.
