Quem ganha?

Em cada caixa há regras de cor conflitantes. Aposte verde ou vermelho antes de olhar o resultado. Depois confira no DevTools: Elements → Styles. As regras perdedoras aparecem riscadas — e o painel Computed mostra quem venceu.

1 — id contra class

#alvo1     { color: verde;    }
.vermelho1 { color: vermelho; }

Aposte a cor

2 — class contra id + elemento

.verde2 { color: verde;    }
#c2 p   { color: vermelho; }

Aposte a cor

3 — empate técnico

.empate { color: vermelho; }
.empate { color: verde;    }

Aposte a cor

4 — style no atributo

#alvo4 { color: verde; }
<p style="color: vermelho">

Aposte a cor

5 — !important

#alvo5 { color: verde !important; }
<p style="color: vermelho">

Aposte a cor

6 — uma classe contra duas

.b6    { color: vermelho; }
.a6.b6 { color: verde;    }

Aposte a cor

7 — nenhuma regra no alvo

#c7 { color: verde; }
/* nada declarado no <p> */

Aposte a cor

8 — seletor descendente

.card8 span            { verde;    }
.card8 .destaque8 span { vermelho; }

Aposte a cor
